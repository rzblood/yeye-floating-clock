# 椰椰桌面时钟

一款面向 Windows 10/11 的透明桌面时钟、闹钟与桌面宠物应用。

## 使用

1. 双击 `椰椰桌面时钟-1.0.0-x64-免安装版.exe` 直接运行；安装版则运行 `椰椰桌面时钟-1.0.0-x64-安装版.exe` 并按向导安装。
2. 单击宠物上方的时钟，或右键宠物，打开闹钟面板。
3. 选择时间、填写名称并点击“添加”。闹钟默认每天触发。
4. 拖动宠物可以移动位置；双击宠物可以让她跳跃。
5. 宠物会把屏幕边缘和可见应用窗口边缘当成障碍物或平台。
6. 托盘菜单可以重新显示宠物、暂停活动或退出。

## 视觉状态

- 白天启动与闹钟：太阳形态。
- 常驻状态：紫色番薯宠物。
- 夜间启动与退出：月亮形态。
- 启动时太阳或月亮从桌面边缘升起，然后过渡为滚入的圆番薯；退出时反向落下。

## 本地开发

```powershell
npm install
npm start
```

构建 Windows 安装版和免安装版：

```powershell
npm run dist:win
```

## 说明

- Windows 的“开机启动”选项由系统登录项实现。
- 窗口障碍物识别只读取可见窗口的位置和大小，不读取窗口内容。
- 宠物动画按 60 FPS 更新；实际流畅度仍会受到 Windows 显示刷新率和系统负载影响。
- 未进行代码签名的首次运行可能出现 Windows SmartScreen 提示，可选择“更多信息”后继续运行。
