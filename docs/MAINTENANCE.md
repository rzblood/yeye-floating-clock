# 椰椰悬浮时钟：维护记录与路线图

本文用于持续维护 `0.2.x` 及后续版本，记录已经验证的设计、被淘汰的方案、平台限制和下一阶段计划，避免后续重复踩坑。

## 当前发布范围

- Windows 10/11 x64：单文件便携 `.exe`，免安装。
- macOS Apple Silicon：`.app.zip`，免安装。
- 不发布 Windows 安装器、Windows 32 位版本或 Intel Mac 版本。
- 当前没有付费代码签名。macOS 首次打开可能需要在 Finder 中右键选择“打开”。

## 0.2.0 已完成

### 体积与架构

- 桌面端采用 Tauri 2 + Rust，前端只使用原生 HTML、CSS 和 JavaScript。
- Rust release 开启 LTO、单 codegen unit、体积优化、去符号和 panic abort。
- 前端构建只复制运行时实际使用的角色、天气和许可文件，不把切图草稿或构建缓存打进应用。

### 角色模型与动画

- 放弃“从原始整图用多边形硬切左右手”的方案。该方案在缩放和 WebKit 插值时会产生肩部裂缝。
- 当前模型由无手身体、完整左手、肩部连接件组成；右手直接复用完整左手并水平镜像，避免缺口和左右质量不一致。
- 身体层覆盖手臂根部，手臂从身体后方围绕固定肩点旋转，因此不会出现双层手或接缝透底。
- 保留单一手型；跳跃、待机挥手和边缘探头只改变同一套手的姿态，不再在动作中切换素材。
- 启动和退出使用番薯弹入/收起动画，删除不符合产品方向的太阳、月亮轨迹过场。

### 窗口与交互

- 宠物可单击跳跃、拖动、自由漫游、休息、镜像和调节至 50%–125%。
- 控制台使用独立固定尺寸，不跟随宠物缩放；面板透明度最低可调至 10%。
- 支持始终置顶和桌面层级。桌面模式获得焦点时临时置顶，失焦后恢复桌面层级。
- 支持屏幕边缘探头：停靠后只露出部分身体，悬停增加可见区域，单击完整返回。
- 打开控制台时隐藏宠物、HUD 和地面阴影，防止透明面板底部透出黑色椭圆。
- Windows 和 macOS 会读取可见窗口边界，用于停靠和攀爬判断；不会读取窗口标题或内容。

### 时间、天气与界面

- 使用 Open-Meteo 获取天气，无需 API Key；默认每 30 分钟刷新。
- 使用网络响应中的时间信息校正应用内时钟，不修改系统时间。
- 天气图标采用 MIT 许可的 Meteocons。
- 液态玻璃默认开启，并统一应用于时钟、天气、控制台、分区、输入框和按钮。
- 折射贴图使用圆角矩形距离场生成，参考 MIT 许可的 `shuding/liquid-glass`；文字位于独立前景层，避免随折射变形。

## 已知限制

### macOS 液态玻璃

WKWebView 对 `backdrop-filter: url(...)` 的 SVG 位移支持不完整，而且透明应用窗口无法直接取得窗口外的桌面像素。因此 macOS 当前使用距离场边缘高光、色散、模糊和系统合成降级，不能完全复现网页在 Chromium 内对背景图片的真实折射。

若以后追求系统级效果，可评估：

1. macOS 26 原生玻璃视图，并为旧系统保留现有降级样式。
2. 原生窗口背景采样加 GPU shader。该方案可能触发屏幕录制权限，性能和隐私成本较高，不应默认启用。

### 自动漫游与攀爬

- 窗口平台检测是几何启发式，不理解窗口真实形状。
- 多显示器、自动隐藏 Dock、系统菜单和快速移动窗口仍可能造成误判。
- 应优先保证可拖动和可恢复，不能为了吸附效果再次锁死宠物。

### 签名

- Windows 便携程序和 macOS 应用目前没有商业签名，系统可能显示未知发布者提示。
- 不应把证书、私钥或签名密码提交到仓库；未来通过 GitHub Secrets 接入签名。

## 回归测试清单

每次发布前至少检查：

1. `npm run check`、`npm run frontend:build` 和目标平台 release 构建通过。
2. 启动/退出没有中轴旋转或太阳月亮过场。
3. 左右手轮廓完整、只有一层、肩部无裂缝；跳跃和挥手不换手型。
4. 宠物可以拖动，单击与拖动不会选中文本或图片。
5. 50%、82%、100% 和 125% 尺寸下 HUD 不裁切，控制台保持可读。
6. 控制台靠近四个屏幕边缘都能打开和关闭，底部没有宠物阴影透出。
7. 始终置顶、桌面层级、焦点临时置顶和失焦恢复都符合预期。
8. 边缘探头的停靠、悬停和单击返回可用。
9. 自由漫游与安静休息互斥，旧设置不会导致宠物永久不动。
10. 天气失败时不影响时钟；离线时继续使用系统时间。
11. Release 中只有 Windows x64 便携 `.exe` 和 Apple Silicon `.app.zip`。

## 后续路线

### 优先级 A：稳定性

- 增加多显示器、分辨率变化和系统缩放回归测试。
- 为窗口停靠与攀爬增加可视化调试开关，但默认关闭。
- 增加设置文件版本迁移，避免新字段与旧配置组合产生互斥状态。
- 增加本地崩溃日志和“重置窗口位置”入口，不上传遥测。

### 优先级 B：角色表现

- 在不更换手型的前提下增加挥手、伸懒腰、打招呼和睡眠节奏。
- 将动作拆成少量可组合状态，避免多个 CSS 动画同时写入同一个 transform。
- 增加漫游速度、待机频率和边缘探头幅度选项。

### 优先级 C：桌面能力

- 改进多窗口平台识别、跨显示器移动和窗口关闭后的落地行为。
- 增加天气缓存、离线状态和更细的刷新频率。
- 评估原生 macOS 26 玻璃材质，同时保持旧系统和 Windows 的一致降级体验。
- 在签名条件具备后增加自动更新；在此之前继续提供可验证的免安装包。

## 维护约定

- 角色和其他美术资源不属于根目录 MIT 代码许可证，具体见 `ASSET_LICENSE.md`。
- 新增第三方代码或素材前必须确认许可证，并把许可证副本放入仓库。
- 不提交 `target/`、`frontend-dist/`、本地测试包、日志、`.env`、证书或密钥。
- Release 标签必须与 `package.json`、`Cargo.toml` 和 `tauri.conf.json` 的版本一致。
